# Universal Optical Transfer (Fountain-Coded Visual Data Stream)

Transfers files between devices (PC, Phone, Mac) with zero network connection, zero cloud servers, zero Bluetooth/Wi-Fi pairing, using nothing but **a screen and a camera**.

## 🚀 Native & Advanced Features (A–F)

1. **Feature A — Adaptive Autotuning:** Dynamic frame-rate, block length, and screen density auto-scaling.
2. **Feature B — Multi-Code Spatial Grid:** 1x1, 2x2, or 3x3 parallel QR matrix streaming.
3. **Feature C — Camera Optics Control:** Torch/Flashlight toggle, manual focus lock, and exposure control.
4. **Feature D — Image Preprocessing Pipeline:** Adaptive Otsu threshold binarization for low-contrast screen photos.
5. **Feature E — Alignment HUD & Goodput Meter:** Real-time FPS, KB/s goodput meter, and solved block progress bar.
6. **Feature F — High-Density Color Matrix:** Optional 4-color visual channel codec yielding 2x speed boost.
7. **Android APK Sharing:** Extract and transfer installed Android apps (`.apk`) directly between phones over light.
